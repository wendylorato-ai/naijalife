# NaijaLife v1.1.0-alpha — Realism & Controls Update

## What’s new

- **Fullscreen 3D** — canvas fills the screen (portrait + landscape); thin floating HUD
- **Turning** — Q/E on desktop; **↺ L / R ↻** buttons on mobile; movement is relative to where you face
- **Improved character** — better human proportions, hair, shoes, walk animation
- **City step-up** — warmer Lagos-like palette, denser palms, better road/vehicle shapes, lighting
- Mobile **CAR** and **USE** buttons for vehicle / interact
- Same systems: jobs, rent, missions, wallet, drive

## Controls

| Action | Desktop | Mobile |
|--------|---------|--------|
| Move | WASD | D-pad |
| Turn | Q / E | ↺ L · R ↻ |
| Run | Shift | RUN |
| Vehicle | F | CAR |
| Interact | E | USE |

## Honest note on realism

This is still **real-time web 3D with procedural meshes**, not photoreal film CGI or GTA-level art. True Lagos photoreal needs custom glTF assets over time. This update fixes feel (turn, fullscreen) and moves the look toward a denser, warmer district while we keep shipping playable builds.
